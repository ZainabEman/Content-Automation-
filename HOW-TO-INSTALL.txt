HOW TO INSTALL CONTENT AUTOMATION
=================================

You need: a Windows 10 or 11 PC, internet, your GitHub account (with access to the project)
and the private .secrets folder I send you. About 30 minutes.


1. Install Git with SETUP.bat
   - Open the project page on GitHub (the link I sent you) and sign in.
   - Click SETUP.bat, then the "Download raw file" button. Save it in Downloads.
   - Double-click SETUP.bat in Downloads.
     Blue "Windows protected your PC" warning: click "More info", then "Run anyway".
     "Do you want to allow this app to make changes?": click Yes.
   - It installs Git. When it says "Press any key", close the window.

2. Get the project (clone)
   - Open File Explorer and go to the folder where the project should live (e.g. Documents).
     Choose it now: don't move the project folder later.
   - Click the address bar at the top, type  cmd  and press Enter. A black window opens.
   - Type this line (with the link I sent you) and press Enter:
         git clone <repo-url>
     If a GitHub sign-in window opens, sign in.
   - A new project folder appears. Close the black window.

3. Set up the project
   - Open the new project folder and double-click SETUP.bat (the one inside the folder).
   - It installs uv, Python, the app and FFmpeg, creates the empty folders and checks
     everything. The first run takes 5-15 minutes. (The .env settings file comes with the project.)
   - Green OK = good. Red PROBLEM = read the yellow line under it.
   - It will still say "key file missing": step 4 fixes that.

4. Your data from Zainu
   - At setup, Zainu copies state\registry.db, .env and .secrets\ to your PC
     (USB stick or password manager, never e-mail), into the project folder:
       <project folder>\state\registry.db
       <project folder>\.env
       <project folder>\.secrets\google_oauth_client.json and the other files
   - Double-click SETUP.bat again. It should end with "ALL OK".
   - SETUP.bat also puts two shortcuts on your desktop:
     "Content Automation - Update" and "Content Automation folder".

5. Codex Desktop
   - If Codex Desktop is missing, SETUP.bat opens the download page. Install it and sign in.
   - In Codex: "Add new project" (Ctrl+O) > choose the project folder (it contains AGENTS.md).
   - Under the message box keep "Ask for approval".
   - Internet for commands: do section 3 of docs\SETUP-CODEX.md once.
   - Connect these plugins in Codex and sign in:
       Gmail         with brandedgenius.de@gmail.com (reads the newsletters)
       Higgsfield    with the company account (Roman's images and video clips)
       Google Drive  with the company account (uploads and the Content Tracker)

6. First test
   Type in Codex:  show calendar
   You should see this week's or next week's content plan.
   Full check: type  Run uv run ca doctor  (every [FAIL] line has a "Fix:" line under it).

7. Get updates
   - To update: double-click UPDATE.bat (or the "Content Automation - Update" desktop shortcut).
   - It ends with "Update OK". If it says "Please send this screen to Zainu", do exactly that
     and change nothing yourself. It never deletes or resets anything.
   - If I tell you to, double-click SETUP.bat again. Running it again is always safe.

DON'T EDIT, DON'T COMMIT
   - These stay only on your PC and never go to GitHub (git ignores them):
       .secrets\   outputs\   state\
     Never send .secrets to anyone. Never paste a key into .env, Codex, a chat or a screenshot.
   - .env comes with the project and is shared on GitHub: don't edit it (a change blocks updates).
   - Never edit files in config\ or commit anything (no git commit, no git push).
     You only update with UPDATE.bat. Your finished content is in outputs\.

Something wrong? Double-click SETUP.bat again. If a red PROBLEM line stays, send me a photo of it.
